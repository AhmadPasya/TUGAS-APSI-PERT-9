## Penjelasan Singkat

Sistem Informasi Laundry digunakan untuk membantu proses pengelolaan layanan laundry mulai dari pendataan pelanggan, pencatatan transaksi laundry, pengelolaan pembayaran, hingga pembuatan laporan. Sistem ini bertujuan untuk mempermudah proses bisnis laundry agar lebih cepat, akurat, dan terstruktur dibandingkan dengan pencatatan manual.

## Tujuan

- Mempermudah pengelolaan data pelanggan.
- Mempermudah pencatatan transaksi laundry.
- Mengotomatisasi perhitungan biaya laundry.
- Mempermudah pengelolaan pembayaran.
- Menyediakan laporan transaksi yang akurat.

## Ruang Lingkup Sistem

Sistem ini mencakup proses berikut:

- Pendataan pelanggan.
- Pendataan layanan laundry.
- Pengelolaan transaksi laundry.
- Pengelolaan pembayaran.
- Pengelolaan laporan transaksi.

2. Pengguna membuka sistem.
3. Pengguna memasukkan data.
4. Sistem melakukan validasi data.
5. Jika data valid, sistem menyimpan data.
6. Jika data tidak valid, pengguna diminta memperbaiki input.
7. Sistem menampilkan hasil atau laporan.
8. Selesai.
